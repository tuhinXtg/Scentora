# Scentora Project Development Plan

## Overview

Scentora is a production-oriented full-stack e-commerce platform for a perfume business.

The goal is to create:

- A customer-facing shopping experience
- An admin dashboard for store operations
- A structured backend API
- A reliable relational data model
- Secure authentication and authorization
- A documented, testable, and deployable codebase

## Primary Goals

- Build a complete customer e-commerce website
- Build an admin dashboard
- Create a structured backend API
- Design a reliable database
- Implement secure auth and authorization
- Support products, inventory, orders, customers, cart, checkout, and payments
- Add validation, error handling, logging, and security
- Test core business workflows
- Deploy the application
- Maintain clear documentation

## Development Principle

Every technology, service, and architectural decision should have a clear purpose in the application.

The focus is to build a structured, secure, maintainable, and deployable e-commerce platform for managing a perfume business.
