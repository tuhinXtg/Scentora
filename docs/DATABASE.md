- User
- Admin

- Inventory

- Address

- Payment
- Coupon
- Review
- Rating
- Notification

## Design Rules

The final schema should define:

- Primary keys
- Foreign keys
- Relationships
- Constraints
- Indexes
- Unique constraints
- Timestamps
- Deletion strategy

## Important Requirement

Historical orders should preserve the product and price information that existed when the order was placed.
